# Model of Distribution of Instances by Containers

Модель распределения экземпляров по контейнерам на C# (.NET).
Лабораторная работа №2 по объектно-ориентированному программированию (ИТМО).

## Описание

Программа моделирует размещение экземпляров (объектов) по контейнерам
с учётом ограничений по весу, габаритам и товарному соседству.
При невозможности разместить экземпляр модель сообщает об ошибке.

## Структура проекта

```
src/Lab2/            — исходный код модели
tests/Lab2.Tests/    — модульные тесты
```

## Требования

- .NET SDK 10.0

## Сборка и запуск

```bash
dotnet build
dotnet test tests/Lab2.Tests
```
